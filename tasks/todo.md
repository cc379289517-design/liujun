# 需求：区域地图熨烫机工作态展示与后台管理

## 当前阶段：已实现并验证

### 已理解目标

- 在各区域平面地图右上角显示当前正在工作的熨烫机数量。
- 熨烫机图标后方显示承接任务的助理头像，并用气泡显示任务信息：
  - `xx熨烫任务`
  - `xx分钟`
  - `已进行x分钟`
  - 若超时，追加显示超时多久。
- 原本地图上承接熨烫任务的助理头像框改为灰色，代表人暂时离开去熨烫机工作。
  - 灰色状态文案：`熨烫中已进行x分钟`。
- 后台管理「空间管理」中新增「熨烫机管理」。
  - 可按区域手动添加熨烫机数量。
  - 熨烫机状态可调整：`正常运行` / `维修不可用`。
  - 后台添加的熨烫机直接显示在对应区域的平面地图中。
